# Couchy

Медиацентр для Android-телефонов, планшетов и Android TV приставок: один плеер и одна медиатека для онлайн-видео, торрентов, IPTV и своих файлов. Управление пультом и сенсором.

Концепция и макеты лежат в проекте (video/concept.md, video/screens).

## Что уже есть

- Три раскладки: ТВ (пульт, рамка фокуса), планшет и телефон; тёмная и светлая темы
- Открытие видео по ссылке (mp4, mkv, webm, HLS .m3u8, DASH .mpd), из файла и через «Открыть с помощью» из других приложений
- Медиатека: «Продолжить просмотр», избранное, история, фильтры и сортировка
- Плеер на Media3: память позиции, выбор озвучки, субтитров, качества, скорости и масштаба, запоминание языка дорожек, управление пультом и жестами
- Устойчивость к долгому фону: новый запуск всегда обрабатывается как новый запрос

## Сборка

Каждый пуш в `main` собирает APK в GitHub Actions и публикует релиз `build-N`:
https://github.com/binkoiv-afk/couchy/releases/latest

Для стабильной подписи (чтобы обновления ставились поверх) в настройках репозитория нужен секрет `KEYSTORE_PASSWORD`. Без него сборка подписывается отладочным ключом.

Скриншоты экранов рендерятся в CI (Paparazzi) и прикладываются к служебному релизу `probe`.
